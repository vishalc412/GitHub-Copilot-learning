Session 5 — Code Review Calibration

How good is Copilot's automated review, on YOUR code?

15:45–16:30 · 45 min

Full detail: copilot-instructions/agents/06-code-review.md (preview of Day 3's agentic material).

🧪 Exercise — Calibration Pass
  1. Pick 5 recently merged PRs from a real repo
  2. Request a Copilot review on each (open a fresh PR with the same diff if needed)
  3. Mark every comment: "would have caught a real bug" / "correct but minor" / "not applicable"
  4. Share the ratio as a group — this sets realistic expectations before Day 3's automation topics

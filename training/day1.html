Session 3 — The Art of Prompting

The five elements of a great prompt

13:00–14:30 · 90 min

1. Action

What to do — validate, calculate, transform, parse

2. Subject

What to act on — user, order, dataset, request

3. Details

Specific requirements the function must satisfy

4. Constraints

Limits, rules, things it must NOT do

5. Output

Expected return shape/type

Signature-first pattern — define the full type signature before letting Copilot fill in the body:

def calculate_order_total(
    items: List[Dict[str, float]],
    discount_code: Optional[str] = None,
    tax_rate: float = 0.08
) -> Dict[str, float]:
    """
    Calculate order total with itemized breakdown.
    Returns: {'subtotal', 'discount', 'tax', 'total'}
    """
    # Let Copilot complete

Walk through 3–4 patterns from copilot-instructions/patterns/prompt-patterns.md live: Signature-First, Example-Driven, Step-by-Step, Contract.

Session 5 — The 10 Mastery Rules Workshop

Team speed-run through the rulebook

16:00–16:45 · 45 min

Full detail: copilot-instructions/rules/copilot-mastery-rules.md. In pairs, each team takes 2 rules and demos one exercise from that rule to the group in under 5 minutes.

#RuleOne-line takeaway
1Context is KingMore relevant open files/types = better suggestions
2Comments Before CodeCopilot reads comments as instructions, not decoration
3Type EverythingType hints are the highest-leverage context signal
4Use Design PatternsNamed patterns (Repository, Factory...) get recognized instantly
5Test-Driven DevelopmentTests-first gives Copilot an exact spec to implement against
6Incremental ComplexityLayer features on working code rather than one giant prompt
7Use Copilot Chat EffectivelySpecific questions beat "fix this"
8Keyboard Shortcuts MasterySpeed compounds over thousands of interactions/day
9Review Before AcceptNever trust a suggestion you haven't read
10Continuous LearningClean, consistent code teaches Copilot your codebase
